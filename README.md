Featured Project
Smart Monitoring System for Electricity Distribution Infrastructure
A project exploring how data and technology could help improve visibility into Eskom's distribution infrastructure, particularly distribution transformers.
The system monitors electricity usage and looks for unusual patterns that could indicate overloading, faults, illegal connections, cable theft, or unexpected power interruptions.
The project uses simulated electricity-meter data to recreate different scenarios and explore how a system could detect and respond to abnormal events.
